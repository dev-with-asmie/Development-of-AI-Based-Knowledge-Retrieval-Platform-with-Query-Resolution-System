# M1.4 – Semantic Retrieval and Accuracy Evaluation

## 1. Objective

The objective of this phase was to implement semantic retrieval functionality and evaluate the retrieval performance of the AI-Based Knowledge Retrieval Platform using sample documents from two different domains.

## 2. Semantic Retrieval Implementation

A semantic retrieval service was developed using Sentence Transformers and Qdrant.

The retrieval pipeline consists of:

1. Accepting a natural-language user query.
2. Generating a query embedding using `sentence-transformers/all-MiniLM-L6-v2`.
3. Converting the query into a 384-dimensional vector.
4. Performing cosine similarity search in Qdrant.
5. Retrieving the most relevant document chunks.
6. Returning the source filename, chunk index, text and similarity score.

The retrieval service also supports filtering results by selected document filenames.

## 3. Evaluation Dataset

Two sample documents were created and indexed in Qdrant.

| Domain | Document | Chunks |
|---|---|---:|
| Academic Administration | academic_policy_sample.txt | 4 |
| Computer Networking | networking_sample.txt | 3 |
| **Total** | **2 documents** | **7** |

Both documents were successfully processed using the document ingestion pipeline. Each chunk was converted into a 384-dimensional embedding and stored in the Qdrant collection.

## 4. Evaluation Methodology

Ten test questions were prepared, consisting of five questions from each domain.

Each question was associated with its expected answer-containing document chunk.

The following evaluation metrics were used:

- **Hit@1:** Checks whether the expected chunk appears in the first retrieval result.
- **Hit@3:** Checks whether the expected chunk appears within the top three results.
- **Hit@5:** Checks whether the expected chunk appears within the top five results.

The evaluation was conducted using the implemented semantic retrieval service.

## 6. Technologies Used

## 7. Conclusion

The semantic retrieval module was successfully implemented and tested using sample documents from two different knowledge domains.

The evaluation achieved 100% Hit@1, Hit@3 and Hit@5 across ten test questions.

These results demonstrate successful retrieval performance on the prepared evaluation dataset. Further testing with larger datasets, more diverse queries and additional knowledge domains would be required to establish general retrieval performance.

## 8. Limitations

- The evaluation used two sample documents and ten test questions.
- The evaluation measured retrieval performance, not the factual correctness of generated answers.
- Response generation and multi-agent orchestration were not evaluated as part of this retrieval test.
- Further evaluation with larger and more diverse datasets is recommended.
